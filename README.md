# Olayokun-Olasunkanmi

> Expo calculator app — Git assignment submission

## 🧮 About the App

I built this calculator with React Native using the Expo framework. It handles the four basic operations, prevents duplicate decimal points, and resets cleanly with the AC button. Dark mode is supported automatically based on the device setting.

## 🎨 Design

The app uses a fuchsia/pink accent colour. I picked this because it looks good in both light and dark mode and gives the app a distinctive feel.

## 🚀 Quick Start

```bash
# Install packages
npm install

# Run the dev server
npx expo start
```

Then scan the QR code in the Expo Go app.

## 📁 Key Files

- `components/calculator.tsx` — all calculator logic and UI
- `constants/theme.ts` — colour definitions
- `app/(tabs)/index.tsx` — home tab (calculator)
- `app/(tabs)/explore.tsx` — notes/info tab
